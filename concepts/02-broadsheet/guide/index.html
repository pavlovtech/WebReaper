CREATIVE DIRECTION

WebReaper's own metaphor (a reaper, a harvest, sheaves of pages) is a nineteenth-century image, so this concept takes it at its word: the product announcement as an 1890s broadsheet. Where the sibling concepts are a live terminal and an interactive workbench, this one is deliberately print: justified columns, hairline rules, stacked deck headlines, engravings, a classifieds column, and almost no motion. Features become editorial forms. The escalation ladder is a correspondent's dispatch; the architecture is a patent filing; the autonomous agent gives an interview; the fifteen NuGet packages take out classified advertisements; the Firecrawl comparison is a commodities table. The register is literal, which is why the paper is paper-coloured: the page is the object it depicts.

WHAT IS REAL

  • Every command, flag, and API call was checked against the shipped v11.3.x binary's help text and the repository README before typesetting. The "By Electric Telegraph" dispatches quote a real webreaper map run and a real self-scrape of webreaper.ai captured on 2026-07-10.
  • The wire-key escalation sequence is labelled a dramatisation in print, and the box says nothing is scraped from the page. The ladder it dramatises (HTTP to browser to stealth, host-sticky floors, blocked pages dropped with a non-zero exit) is the documented ADR-0083 behaviour.
  • The four engravings were generated with gpt-image-2 for this edition (prompts specified: period wood-engraving and stipple styles, cross-hatching, no text), then compressed to WebP. They are credited as such in the imprint; no claim of period provenance is made.

IMPLEMENTATION

  • One static HTML file on a 12-column grid with explicit spans; vertical column rules are borders on the grid items, exactly as a compositor would rule a chase. Body copy is justified with hyphens:auto; code tokens are exempted (hyphens:none) so an identifier never breaks with a false hyphen a reader might copy.
  • Typography: UnifrakturMaguntia for the masthead only; Bodoni Moda for headlines and decks (the high-contrast Didone of the period press); Libre Caslon Text for body; Courier Prime for anything commandable. Four families, each with one job.
  • The engravings sit on the paper via mix-blend-mode:multiply, so their own backgrounds vanish into the page tone and the ink reads as printed, not pasted.
  • The one interaction, "tap the key", reveals telegraph dispatches paced by wall-clock due-times (a lesson from the terminal concept: background-tab timer clamping must never serialize an animation). Reduced-motion prints instantly; with scripts off, a noscript rule simply reveals all lines.
  • Aged paper is layered CSS radial gradients; no noise filters, no texture images. The corners darken the way a folded paper actually tones.

ACCESSIBILITY & PERFORMANCE

  • Semantic articles and figures with period-voice alt text; the dispatch list is aria-live; clip buttons are real buttons; ink on paper measures about 12:1, and the oxblood accent about 7:1.
  • Images carry width/height (no layout shift), lazy-load below the fold, and total ~1.7 MB WebP for four full engravings. No JS libraries; the whole script is the clip buttons and the wire key.

ITERATION LOG

  • PASS 1 · STRUCTURE & COPY First full-page review: swept every em-dash out of the prose to house style (period conventions notwithstanding); replaced justified setting with rag-right in the narrow interview column where rivers formed; exempted code tokens from hyphenation after spotting a broken-in-half builder call; filled the right rail's dead space with the "To Agents Entering Service" notice; gave the telegraph box an "awaiting transmission" resting state so it never reads as empty.
  • PASS 2 · TYPESETTING DETAIL Rewrote the lead paragraph so the long Homebrew tap never breaks mid-token in the first column a reader sees (the full command lives in Stop Press, where it can scroll); re-verified the market table, parts schedule, and classifieds against FACTS.md; confirmed the wire key replays cleanly and relabels itself.
  • PASS 3 · SMALL FORMATS 375 px pass: the twelve columns collapse to one with rules turned horizontal, the ears retire, the dateline centres, install commands scroll inside their rows with no page overflow; re-checked telegraph, clip buttons, and image lazy-loading on the tall single column.

REPRODUCE THIS WORKFLOW

1. verify before typesetting: run the real binary, save transcripts,
   keep a FACTS.md every sentence must trace to
2. write the copy as journalism first (headlines, decks, dispatches,
   classifieds); the layout follows the copy
3. generate engravings in one consistent period style (gpt-image-2:
   wood engraving, cross-hatch, stipple, "no text"); webp; multiply-blend
4. set the sheet: 12-col grid, hairline rules, justified Caslon,
   Bodoni heads, blackletter masthead only
5. iterate x3 with full-page screenshots (1440 and 375); fix, repeat
6. deploy the directory: vercel deploy --prod
