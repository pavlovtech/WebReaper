GENERAL AVAILABILITY · NO SUBSCRIPTION REQUIRED

THE WEB, REAPED ENTIRE.

An Engine of some Twelve Megabytes turns Any Page to clean Markdown, or to honest JSON; asks for no Docker, no Account, and no Meter.

Bot-Checks overcome by an Automatic Escalation, to the Consternation of Gatekeepers everywhere. Gentlemen of .NET rejoice.

It is the pleasure of this Journal to report the general availability of WebReaper, an engine of the AI-native school which any householder may obtain in a moment by Homebrew (the exact line waits in Stop Press, at right), by a POSIX script, or, for the .NET craftsman, by dotnet add package WebReaper. The whole apparatus weighs about twelve megabytes, requires no runtime whatever, and is issued under the MIT licence, which is to say: yours, even in trade.

Its habits are simple. Commanded webreaper scrape https://example.com, it returns the page as clean Markdown in a tidy envelope of {title, markdown, url}, fit for any modern language-model or an honest pipe. Given --schema, it returns JSON fields instead, cut by CSS selector with deterministic scissors and at no cost in tokens. Commanded webreaper crawl, it takes the whole estate: recursive, on-domain, seeded by sitemap, streaming one JSON line per page as fast as the presses can turn.

The engine presents three faces to the working public: the command-line instrument here described; a fluent library for .NET, in which the same harvest reads .Crawl(url).AsMarkdown().WriteToConsole(); and servers of the Model Context Protocol, by which the mechanical agents now entering domestic service may command it directly. A household keeping a Claude need only say webreaper init, and the skill is installed in the study; thereafter "scrape the morning's headlines" finds the engine without ceremony.

Where intelligence is wanted, namely for schema inference, natural-language extraction, or the autonomous trade, the proprietor brings his own: any IChatClient serves, whether of OpenAI, Anthropic, Ollama, or a llamafile kept in the pantry. Where it is not wanted, the engine spends nothing at all. The Journal has verified every claim in this number against the shipped binary, and prints the receipts in its Prospectus.

THE ESCALATING LOADER, OBSERVED

OVER THE WALL OF 403.

Our Correspondent rides the ladder from plain HTTP to a Headless Browser, and thence, with permission, to Stealth.

The machine first knocks at the front door by plain HTTP, which costs nearly nothing and most commonly suffices. But where a page presents a challenge (a 403 or its cousins, a suspicious header, the watermark of Cloudflare, DataDome, or their kind), the engine, without any instruction, summons a headless Chromium and presents itself again as a browser entire. Should the gate still hold, it asks leave to don the CloakBrowser, a stealth fork of some 220 megabytes fetched only upon consent (--auto-stealth grants it standing, for unattended work).

Mark the economy of the thing: the first confirmed block upon a host lifts that host's floor, so that the remainder of the crawl begins at the working tier and the climb is paid once, not per page. And mark the honesty: a page still blocked at the top of the ladder is dropped, never passed off as goods; the run exits non-zero, that unattended jobs may know the truth of it. Challenge pages shall not masquerade as data in this Journal's columns, nor in yours.

THE PATENT OFFICE.

  1. IScheduler: the queue of work; in-memory, file, SQLite, Redis, or Azure Service Bus.
  2. IVisitedLinkTracker: the memory of ground already covered.
  3. IPageLoadTransport: HTTP in core; Chromium by Playwright or raw CDP; CloakBrowser for discretion.
  4. IContentExtractor: the fold that turns document to data; Markdown, schema, or an LLM adapter.
  5. IScraperSink: delivery of records: Console, CSV, JSON Lines; MongoDB, Redis, Cosmos by satellite.
  6. IAgentBrain: for the autonomous trade, with a durable run store.

Each part a public interface; implement one and the others never notice. Fifteen packages, one version, lockstep.

AN AUTOMATON SPEAKS.

How are you engaged?

By a single line: LlmAgent.RunAsync(url, goal, chatClient). I am given a goal and a door; I decide, persist, then execute, in that order. My run store remembers, so I resume across restarts without repeating myself.

Whose intelligence do you employ?

Any my master provides: OpenAI, Anthropic, Ollama, Azure, a llamafile in the pantry. I am built upon Microsoft.Extensions.AI and hold no allegiance.

And clients of the Model Context Protocol?

Two servers wait upon them: stdio for the desk (Cursor, Claude Desktop), and Streamable HTTP for n8n and its kind, by docker run ghcr.io/alex-on-ai/webreaper-mcp-http. Six tools apiece: scrape, map, extract, and their learned cousins.

THE PRESS ROOM.

The crawl edition is set as JSON Lines: commanded webreaper crawl https://example.com > pages.jsonl, the engine streams one object per page as it is cut, capped politely at a thousand pages unless --max-pages instructs otherwise. Readers of taste pipe a single page through jq -r .markdown and receive prose fit for any prompt.

TELEGRAPHIC INSTRUCTIONS.

FOR THE .NET CRAFTSMAN

using WebReaper.Builders;

var engine = await ScraperEngineBuilder
    .Crawl("https://news.ycombinator.com")
    .AsMarkdown()
    .WriteToConsole()
    .BuildAsync();

await engine.RunAsync();

The same line distributed: exchange three calls, .WithRedisScheduler, .TrackVisitedLinksInRedis, .WithRedisConfigStorage, and many workers share one crawl. For structured fields, a [ScrapeSchema] class is compiled to a reflection-free materialiser by our Roslyn works.

SITUATIONS & APPOINTMENTS.

SCHEDULER, REDIS, distributed, tireless, will share one crawl among any number of workers. Apply .WithRedisScheduler(...).

TRACKER, VISITED-LINK, never forgets an address; SQLite or Redis persuasion. .TrackVisitedLinksInSqlite(...).

SINK, MONGODB, respectable, receives records at all hours. .WriteToMongoDb(...). Cosmos and Redis houses likewise engaged.

TRANSPORT, PLAYWRIGHT, multi-browser, conversant with all ten page actions, Fill and Press included. .WithPlaywrightPageLoader().

CHROMIUM, STEALTH, discreet; ~220 MB upon first engagement; references from ADR-0054. .WithCloakBrowser().

GENERATOR, SOURCE, ROSLYN, turns attributed classes to schemas and materialisers at compile time; no reflection kept on premises.

CHAT CLIENT, AOT-SAFE, OpenAI-compatible, travels light, no SDK baggage. Enquire WebReaper.AI.Http.

SELF-HEALING, SELECTOR, repairs a broken CSS selector once and remembers the cure. .WithLlmSelfHealing(chatClient).

WANTED: BLOCKED PAGES, none. This house drops them and exits non-zero, as advertised.
