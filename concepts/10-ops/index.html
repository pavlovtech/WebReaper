MISSION

WebReaper is an AI-native web scraper: one ~12 MB binary, a .NET library, and MCP servers. MIT, local-first, no accounts. This console replays what its crawl driver actually does: a parallel frontier, per-page bot-check escalation, honest failures, durable agent runs.

Workers share one crawl because the queue and the visited-set are seams, not internals: .WithRedisScheduler(...) · .TrackVisitedLinksInRedis(...) · or Azure Service Bus. Same code, distributed. (The fleet above is part of the simulation.)

WHY THE LADDER MATTERS

Most scrapers make you pick a browser up front and guess when you're blocked. WebReaper starts cheap, detects the block, climbs HTTP → browser → stealth per page, pins the working tier per host, and drops anything still blocked rather than emitting challenge-page garbage. Unattended runs learn the truth from the exit code.
